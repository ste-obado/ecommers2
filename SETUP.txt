FIRST TIME SETUP:
-----------------
1. CREATE AN ADMIN ACCOUNT:
   Since this is your first time, you need to create an admin user in Supabase.

   a) Go to: https://vobewrtddlxthlrsauxx.supabase.co
   b) Sign in to Supabase dashboard
   c) Go to Authentication > Users
   d) Click "Add user" > Create with email
   e) Enter email and password (remember these!)
   f) After creating the user, note the user ID

   g) Go to SQL Editor and run this query (replace with your actual user ID and details):

   INSERT INTO admin_users (id, email, full_name, role)
   VALUES
   ('YOUR_USER_ID_HERE', 'admin@proshop.com', 'Admin User', 'super_admin');

   Example:
   INSERT INTO admin_users (id, email, full_name, role)
   VALUES
   ('a1b2c3d4-e5f6-7890-abcd-ef1234567890', 'admin@example.com', 'John Doe', 'super_admin');

2. LOGIN TO ADMIN PANEL:
   - Visit: http://localhost:5173/admin-login.html
   - Use the email and password you created
   - You'll see the admin dashboard

3. ADD YOUR FIRST PRODUCTS:
   - Click "Products" in the sidebar
   - Click "+ Add Product"
   - Fill in the product details:
     * Title, category, descriptions
     * Price
     * Affiliate link (from Digistore24 or your platform)
     * Image URL (use Pexels.com for free stock photos)
     * Optional: Video URL (direct link to .mp4 file)
   - Set as "Featured" to show on homepage
   - Save!

TROUBLESHOOTING:
----------------
Q: Can't login to admin?
A: Make sure you created the admin user in Supabase and added them to admin_users table

Q: Products not showing?
A: Check product status is "Active" not "Draft"

Q: Images not loading?
A: Verify the image URL is a direct link (ends in .jpg, .png, etc.)

Q: Videos not playing?
A: Use direct .mp4 file URLs, not YouTube/Vimeo embed links
