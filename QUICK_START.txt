🔧 HOW TO ADD PRODUCTS:
=======================
1. Login to admin panel
2. Products → Add Product
3. Enter:
   - Title & category
   - Descriptions (short & full)
   - Price
   - Affiliate link (your Digistore link)
   - Image URL (from Pexels.com or any image host)
   - Video URL (optional .mp4 link)
4. Set Featured = Yes (shows on homepage)
5. Status = Active
6. Save!

🐛 TROUBLESHOOTING:
===================
Q: Can't login?
A: Make sure you added user to admin_users table

Q: Products not showing?
A: Check status is "Active" not "Draft"

Q: Images broken?
A: Verify URL is direct link (ends in .jpg/.png)

Q: Need to change brand name?
A: Edit "ProShop" in HTML files + colors in global.css
